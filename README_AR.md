# دفتر حساباتي — مشروع Android

تطبيق مستقل بواجهة عربية وألمانية لإدارة المداخيل والمسحوبات، ويحفظ البيانات محلياً على الهاتف باستخدام SQLite.

## الوظائف
- واجهة متعددة اللغات: العربية والألمانية، مع إمكانية التبديل من الشاشة الرئيسية.
- تصنيف المسحوبات إلى ثابتة ومتحركة.
- إضافة تاريخ وملاحظات.
- حساب إجمالي المداخيل والمسحوبات والرصيد الحالي تلقائياً.
- تعديل الرصيد الافتتاحي/إقفال الحساب.
- حذف حركة بالضغط المطوّل عليها.
- تصدير نسخة احتياطية CSV متوافقة مع Excel.
- يعمل دون اتصال بالإنترنت، ولا يطلب صلاحيات إنترنت.

## إنشاء APK باستخدام Android Studio
1. ثبّت Android Studio على الكمبيوتر.
2. افتح مجلد `دفتر_حساباتي_Android` من Android Studio.
3. وافق على تثبيت Android SDK عند الطلب، واستخدم SDK Platform 35.
4. انتظر اكتمال Gradle Sync.
5. من القائمة اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. سيظهر APK عادةً داخل `app/build/outputs/apk/debug/app-debug.apk`.

## النسخ الاحتياطي
من داخل التطبيق اضغط «تصدير نسخة Excel احتياطية (CSV)» واحفظ الملف في مجلد تختاره. يمكن فتح CSV باستخدام Excel. البيانات الأساسية تبقى محفوظة محلياً في التطبيق.

## ملاحظة
هذا مجلد مصدر قابل للبناء في Android Studio، وليس ملف APK مُجمّعاً مسبقاً.
